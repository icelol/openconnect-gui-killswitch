# v1.1.3

## English

- Service heartbeat with version, latency and VPN phase indicators.
- Read-only local PF diagnostics in the GUI and `--service-diagnostics`.
- Inline errors leave OFF and Cancel accessible.
- Separate contact, authentication-reply and tunnel deadlines.
- Confirm OFF by reading the owned PF anchor; preserve other programs' rules.
- Accept safe root-rule ordering while rejecting earlier quick bypasses.
- Allow correcting a cached username after an unsuccessful form submission.
- Numeric HTTP response codes without authentication headers or bodies.

Native tests cover heartbeat loss/reconnection, phase timing, OFF after rejected
ON and PF rule ordering. Full VPN login still needs local credentials and target
server validation. Windows system protection is not shipped in this macOS release.

## Русский

- Индикатор службы: ответ, версия и задержка; этап VPN отображается отдельно.
- Локальная диагностика PF из GUI и через `--service-diagnostics`.
- Ошибки не перекрывают переключатель и отмену подключения.
- Раздельные таймеры сети, ответа авторизации и создания туннеля.
- OFF подтверждается чтением собственного anchor; чужие правила сохраняются.
- Совместимые правила после нашего hook не мешают включению защиты.
- Повторная форма позволяет исправить сохранённый логин.
- В журнале есть числовые HTTP-коды без заголовков авторизации и тела запросов.

Нативные тесты проверяют восстановление IPC, таймеры, OFF после отказа ON
и порядок правил PF. Полный вход требует локального ввода данных и проверки
сервера. Windows kill switch в этот релиз macOS не входит.
