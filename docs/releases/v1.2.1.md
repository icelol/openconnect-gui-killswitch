# OpenConnect GUI + Kill Switch v1.2.1

## English

A complete release for **Windows x64** and **macOS Apple Silicon, 27+**.
Windows v1.2.0 has been confirmed working by its user. This patch finalizes
packaging and documentation; the VPN/firewall behavior is retained.

| System | File |
| --- | --- |
| Windows x64 | `OpenConnect-GUI-KillSwitch-Setup-windows-x64-v1.2.1.exe` |
| macOS Apple Silicon | `OpenConnect-GUI-KillSwitch-arm64-v1.2.1.dmg` |
| macOS direct install | `OpenConnect-GUI-KillSwitch-Setup-arm64-v1.2.1.pkg` |

The DMG includes installation, cleanup and recovery launchers. On Windows, choose
**Quit** in the tray menu before update/removal. A fresh installation leaves
protection OFF; an update preserves its selected state. The independent switch
blocks Internet/LAN outside this client's VPN; Connect/Disconnect remain available.
Add your own compatible gateway and enter credentials locally.

Included: GUI source, modified OpenConnect source, dependency source/build inputs,
licenses, verification reports, `RELEASE-MANIFEST.json` and `SHA256SUMS`.
No corporate gateway, profile or credentials are preconfigured.

Native Windows CI covers service status, ON/OFF, existing/new traffic, local
username/password TLS/CSTP and real Wintun exchange, restart, upgrade, recovery
and removal. macOS checks cover PF safety, GUI behavior and actual PKG/DMG files.
Target tests are still needed for individual gateways, DTLS, IPv6 Internet,
sleep/wake, network changes and reboot. Windows EXE and PKG are unsigned; the Mac
application uses an ad-hoc signature without notarization. Intel Mac, Windows
ARM64 and 32-bit builds are not included.

## Русский

Полный релиз для **Windows x64** и **macOS Apple Silicon, 27+**. Пользователь
подтвердил работу Windows v1.2.0. Завершены упаковка обеих платформ и документация;
поведение VPN и блокировки сохранено.

Для Windows скачайте **EXE**, для Mac — **DMG** либо отдельный **PKG** из таблицы.
В DMG также есть восстановление и полная очистка OpenConnect. В Windows перед
обновлением или удалением выберите **Quit** в меню значка в трее.

Первая установка оставляет блокировку выключенной; обновление сохраняет выбранное
состояние. Отдельный переключатель блокирует интернет и LAN вне VPN этого клиента;
Connect/Disconnect доступны независимо. Добавьте собственный совместимый шлюз.

В комплекте исходники приложения, OpenConnect и зависимостей, лицензии, отчёты,
`RELEASE-MANIFEST.json` и `SHA256SUMS`. Корпоративные адреса, профили и учётные
данные в сборку не встроены.

Windows CI проверяет службу, ON/OFF, тестовый TLS/CSTP-шлюз и Wintun, перезапуск,
обновление, восстановление и удаление. В macOS проверяются PF, интерфейс и PKG/DMG.
Реальные шлюзы, DTLS, внешний IPv6, сон, смена сети и перезагрузка требуют целевых
проверок. EXE и PKG не подписаны сертификатом издателя; приложение Mac — ad-hoc
без нотарификации. Intel Mac, Windows ARM64 и 32-битных сборок нет.
