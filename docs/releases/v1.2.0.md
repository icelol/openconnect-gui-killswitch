# v1.2.0

## English

Download the **Windows x64 setup EXE** attached to this release. Existing macOS
packages remain available in [v1.1.3](https://github.com/icelol/openconnect-gui-killswitch/releases/tag/v1.1.3).

- Native Windows x64 client and installer, with a LocalSystem network service,
  WFP protection, bundled TLS roots and Wintun.
- One independent ON/OFF switch; Connect, Cancel and Disconnect remain available.
- Persistent blocking, temporary service-only gateway/DNS permissions and exact
  tunnel interface/address permissions. No global firewall reset.
- Service version/latency, connection phase, local diagnostics and administrator
  recovery. Closing the GUI does not disable protection.
- Updates retain the selected protection state. Removal clears only this
  project's network policy and service files.
- Update/removal preflight detects an open interface before stopping the service,
  retaining protection and reporting which action is required.
- English/Russian Windows guides, dependency versions/licenses and corresponding
  modified OpenConnect source.
- Shared service code retains the macOS PF backend and its safety/UI tests.

Windows validation runs on a disposable Windows Server 2022 x64 runner, including
the installed runtime, local username/password TLS/CSTP fixture and real Wintun
packet flow. See the attached verification report for actual outcomes and IPv6
availability. Real Windows 10/11 endpoints, your gateway, DTLS, sleep/wake, network
changes and reboot require target validation. The Windows EXE is unsigned; the
macOS application uses an ad-hoc signature and is not notarized.

## Русский

Скачайте **установщик Windows x64 EXE** из вложений к этому релизу. Пакеты macOS
остаются доступны в [v1.1.3](https://github.com/icelol/openconnect-gui-killswitch/releases/tag/v1.1.3).

- Клиент и установщик Windows x64: служба LocalSystem, WFP, публичные CA и Wintun
  входят в комплект.
- Отдельный переключатель ON/OFF; Connect, Cancel и Disconnect работают независимо.
- Блокировка сохраняется; шлюз и временный DNS разрешены только службе. Для туннеля
  проверяются интерфейс и адрес. Общего сброса firewall нет.
- Индикатор ответа/версии службы, этап подключения, локальная диагностика и
  восстановление администратором. Закрытие GUI не снимает защиту.
- Обновление сохраняет выбранное состояние. Удаление снимает собственные правила
  и убирает службу проекта.
- При открытом окне клиента обновление и удаление останавливаются до изменения
  службы: защита сохраняется, установщик просит закрыть интерфейс.
- Инструкции EN/RU, версии/лицензии зависимостей и изменённые исходники OpenConnect.
- Общий код службы сохраняет PF в macOS и проверки безопасности и интерфейса.

Проверки Windows выполняются на временной Windows Server 2022 x64, включая
установленную программу, локальный TLS/CSTP-сервер с логином/паролем и настоящий
обмен пакетами через Wintun. Фактические результаты и доступность IPv6 указаны
в приложенном отчёте. Реальные Windows 10/11, ваш шлюз, DTLS, сон, смену сети
и перезагрузку нужно проверить на целевых ноутбуках. Windows EXE не подписан;
подпись приложения macOS — ad-hoc, без notarization.
