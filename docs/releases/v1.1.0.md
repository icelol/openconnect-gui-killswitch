# OpenConnect GUI + Kill Switch v1.1.0

## English

First public release with configurable gateways and bilingual documentation.

- No organization-specific server, profile, internal Git remote or credentials.
- Fresh public Git history, preserving upstream attribution and license notices.
- Any validated HTTPS gateway and any protocol compiled into libOpenConnect.
- Kill switch can be enabled without a profile; Connect stays independent.
- Gateway changes retain blocking and replace the endpoint allowlist.
- Bounded root-only DNS bootstrap to macOS-configured resolvers; temporary rules
  and states are removed after the lookup, including failure and cancellation.
- First-connection/duplicate-click regression and multi-gateway/protocol tests.
- Full cleanup and recovery available through the installer and DMG.

Apple Silicon, macOS 27+. Ad-hoc app signature; no Developer ID or notarization.
Tests use injected PF and VPN sessions with the real PF parser. Server-specific
authentication, sleep/wake, network changes and reboot require testing on a Mac.

## Русский

Первая публичная версия с выбором собственных шлюзов и документацией на двух языках.

- Нет адреса организации, готового профиля, внутреннего Git-сервера или паролей.
- Новая публичная история Git с сохранёнными уведомлениями и лицензиями upstream.
- Любой допустимый HTTPS-шлюз и протокол из установленной libOpenConnect.
- Kill switch включается без готового профиля; Connect работает отдельно.
- Смена шлюза заменяет исключения, сохраняя общую блокировку.
- Ограниченный по времени DNS только для root к DNS-серверам macOS; исключение
  и его состояния удаляются после запроса, в том числе при ошибке или отмене.
- Тесты первого Connect, повторных нажатий, смены шлюза и выбора протокола.
- Полная очистка и восстановление через установщик и команды из DMG.

Apple Silicon, macOS 27+. Подпись ad-hoc, без Developer ID и notarization.
PF/VPN в тестах подменяются; синтаксис правил проверяет настоящий PF parser.
Вход на конкретный сервер, сон, смена сети и перезагрузка требуют проверки на Mac.
