# OpenConnect GUI + Kill Switch v1.2.2

The macOS installer now keeps authenticated recovery available when an existing
boot configuration is malformed. A fresh configuration that cannot be created
still fails installation. The package checks its actual minimum macOS and CPU
architecture before stopping an installed client, and reports the exact failing
installation stage in the Installer log.

This release also includes the reviewed OFF recovery, bounded Windows DNS,
nonblocking command channel and login-cancellation fixes previously in main.
Existing malformed policy is preserved; installation never silently converts an
unknown ON intent to OFF. Explicit OFF repairs it and keeps a protected backup.

## Verification

- Original v1.2.1 installed successfully on a MacBook and a separate clean Mac mini.
- A controlled malformed `boot.json` reproduced v1.2.1's postinstall failure on the mini.
- New preflight and installer failure/recovery paths have sandbox regression tests.
- Final v1.2.2 package and installed-service results are recorded in the release reports.
- A successful test here does not identify the cause of an unlogged failure on another Mac.
- macOS27+ AppleSilicon. Intel and older macOS require a separate compatible build.

## По-русски

Исправлена установка при повреждённой существующей конфигурации: служба теперь
запускается с доступным управлением восстановлением, а состояние защиты честно
показывается неподтверждённым. Явное OFF исправляет конфигурацию. Проверки
архитектуры и версии macOS выполняются до остановки старого клиента. При иной
ошибке журнал сообщает точный шаг `OPENCONNECT_INSTALL_FAILED stage=...`.

Обычная установка исходной1.2.1 на двух тестовых Mac прошла. Отказ при повреждённом
состоянии воспроизведён отдельно; это подтверждённый сценарий ошибки, а не
доказанная причина каждого сообщения об отказе установки.
