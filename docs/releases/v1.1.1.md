# OpenConnect GUI + Kill Switch v1.1.1

## English

Fix recovery errors locking users out of the OFF control.

- Keep authenticated service controls available when PF restoration fails;
  show the failure without claiming verified protection.
- Installation checks control readiness separately from firewall protection.
- Add an explicit OFF button independent of the checkbox and selected profile.
- Add `--service-disable`; confirm success only after the service reports OFF.
- Recovery launcher uses ordinary service OFF when supported, with administrator
  recovery retained for an unavailable service.
- Record firewall request/result states without gateway addresses or credentials.
- Regression tests cover PF root-policy conflicts and an unchecked switch after
  failed recovery; existing stale-token and foreign-PF-reference tests retained.

Only this application's PF anchor/reference is removed. Other applications may
keep PF enabled; this does not mean OpenConnect blocking remains active.

Apple Silicon, macOS 27+. Ad-hoc signature, no Developer ID or notarization.

## Русский

Исправлено отключение блокировки после ошибок восстановления PF.

- При ошибке восстановления служба сохраняет управление и показывает проблему,
  не заявляя о подтверждённой защите.
- Установщик проверяет доступность управления отдельно от состояния защиты.
- Отдельная кнопка OFF работает независимо от галочки и выбранного профиля.
- Команда `--service-disable` сообщает успех после подтверждения OFF службой.
- Восстановление использует службу, если она поддерживает явное OFF;
  при недоступной службе остаётся восстановление с паролем администратора.
- Журналируются запрос и результат переключения без адресов шлюза и паролей.
- Добавлены тесты конфликта правил PF и выключения при уже снятой галочке.

Удаляются только правила и ссылка PF этой программы. Другие приложения могут
оставлять PF включённым; это не означает, что блокировка OpenConnect осталась.

Apple Silicon, macOS 27+. Подпись ad-hoc, без Developer ID и notarization.
