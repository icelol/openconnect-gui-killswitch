# OpenConnect GUI + Kill Switch v1.1.2

## English

Fix login compatibility and expose connection diagnostics in the GUI.

- Optional per-profile TLS 1.2 and legacy Cisco login without XML POST.
- Certificate/hostname verification retained; no TLS 1.0/1.1 or obsolete ciphers.
- Password-only service flow does not advertise unsupported browser SSO.
- Forward bounded, sanitized connection progress to View log.
- Report pre-login network/TLS errors separately from authentication failures.
- A 20-second connection deadline does not interrupt an open password prompt.
- Pin and build OpenConnect 9.21 with a small LGPL compatibility patch; include
  complete corresponding library source as a release asset.
- Isolate regression-test settings explicitly from the normal user profiles.

The real-gateway probe reached a trusted TLS 1.2 Cisco login form and cancelled
before submitting credentials. A successful full VPN login still requires the
user's local username/password and server-side authorization.

Apple Silicon, macOS 27+. Ad-hoc signature; no Developer ID/notarization.

## Русский

Исправлена совместимость входа; диагностика подключения теперь видна в GUI.

- В профиле доступны TLS 1.2 и вход Cisco без XML POST.
- Сохраняется проверка сертификата и имени сервера; старые TLS/шифры не включаются.
- Служба с входом по паролю не предлагает неподдерживаемую браузерную SSO.
- В View log передаётся ограниченный журнал с фильтрацией секретов.
- Сетевые/TLS-ошибки до формы входа отличаются от ошибки авторизации.
- Тайм-аут подключения 20 секунд не прерывает открытый запрос пароля.
- OpenConnect 9.21 собирается из проверенного исходника с небольшой LGPL-поправкой;
  полный соответствующий исходник библиотеки включён в релиз.
- Настройки тестов явно изолированы от обычных пользовательских профилей.

Пробник на реальном шлюзе прошёл доверенный TLS 1.2 и получил форму Cisco,
затем отменил вход до отправки учётных данных. Полный вход требует локального
ввода логина/пароля пользователем и разрешения сервера.

Apple Silicon, macOS 27+. Подпись ad-hoc, без Developer ID/notarization.
